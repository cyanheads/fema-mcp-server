# 0.1.14 — 2026-08-23

## Added

- **`fema_dataframe_drop`** removes one staged DataCanvas table or view when `FEMA_ENABLE_CANVAS_DROP=true`; eight tools remain callable by default and the opt-in makes nine.
- **Community health files** add contribution guidance, a code of conduct, funding links, normalized repository attributes, and the dedicated `security@caseyjhand.com` reporting address.

## Changed

- **MCP SDK v2** support from `@cyanheads/mcp-ts-core` now serves the 2026-07-28 protocol, rejects undeclared root tool-input keys, and advertises output and error contracts that match runtime results.
- **Session mode** is explicitly `stateless` across `.env.example`, the Docker image, and the README; `auto` remains documented as the schema default that resolves to stateful.
- **Build and packaging** use Bun 1.4.0, typecheck the test suite under TypeScript 7, produce multi-platform Docker builds from the build platform, and strip platform-specific DuckDB bindings from the portable MCPB asset.
- **Framework tooling and skills** are synchronized to the `@cyanheads/mcp-ts-core` 0.12.3 templates, including SDK v2 testing, definition linting, packaging, and multi-round-trip guidance.
