# 0.1.13 — 2026-07-09

## Fixed

- **`fema_search_nfip`** — canvas `PAGE_SIZE` raised from 1,000 to 5,000. A dense ~49,785-row county-year query now drains in ~10 fetches instead of ~50, finishing well inside typical transport/gateway timeouts; OpenFEMA permits `$top` up to 10,000 rows/page ([#16](https://github.com/cyanheads/fema-mcp-server/issues/16)).
- **`fema_dataframe_query`** — capped canvas results are now disclosed via `ctx.enrich.truncated()`: a `truncated` flag plus `shown`/`cap` land in `structuredContent`, and a matching LIMIT/OFFSET continuation notice renders in `content[]`. The `rows` output description and `query` input description no longer imply an uncapped result ([#19](https://github.com/cyanheads/fema-mcp-server/issues/19)).
