# 0.1.11 — 2026-07-04

## Fixed

- **`fema_dataframe_describe` / `fema_dataframe_query`** — a disabled DataCanvas (`CANVAS_PROVIDER_TYPE` unset) now throws a typed `canvas_unavailable` `ServiceUnavailable` error with a recovery hint pointing to `fema_search_nfip` / `fema_query_dataset`, instead of an untyped `InternalError` ([#14](https://github.com/cyanheads/fema-mcp-server/issues/14)).
- **`OpenFemaService.fetchDataset`** — the `unknown_dataset` and `invalid_filter` throw sites now spread the tool's declared recovery hint into the error data, so `data.recovery.hint` and the `content[]` `Recovery:` line are populated on live errors instead of empty. The raw upstream `name` field is dropped from `invalid_filter` error data ([#15](https://github.com/cyanheads/fema-mcp-server/issues/15)).
