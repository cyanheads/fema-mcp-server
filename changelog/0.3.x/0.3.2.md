# 0.3.2 — 2026-10-03

## Changed

- **Framework error handling** — upgrading through 0.13.7–0.13.11 adds request IDs and automatic declared recovery hints, keeps server stacks and request context out of client errors, and classifies output-contract failures as `InternalError`.
- **Input validation** — safe integers supplied for string fields can be repaired when the resulting string satisfies the schema; rejected arguments carry clearer field paths and guidance.
- **DataCanvas and storage** — canvas scratch files use private directories with isolated spill paths; in-memory storage round-trips values as JSON, matching persistent providers.
- **Telemetry** — the OTLP base endpoint configures traces and metrics; `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` and `LOG_TOOL_FAILURE_PAYLOADS` opt into log export and failed-call payloads. Client log notifications honor `MCP_LOG_LEVEL` and redact sensitive fields.
- **Server adoption** — explicitly validate configuration in `setup()` and use `internalError()` for a capped disaster window missing its boundary date, with a characterization test preserving the error code and message.
- **Development tooling** — sync framework checks for definition imports, packaging, tracked secrets, skill versions, and tag annotations; CodeQL uploads one analysis per language.
- **Documentation** — sync framework guidance, document telemetry settings, and condense the capability reference while clarifying the existing opt-in DataCanvas deletion tool.

## Fixed

- **Registry launch commands** — npm entries use `npx` without npm-script arguments; the HTTP entry sets `MCP_TRANSPORT_TYPE=http` explicitly.
- **Production images** — cross-install target-architecture dependencies in a native build stage, install OpenTelemetry peers at framework-declared ranges with release-age and Socket checks, and remove unused musl bindings from the Debian image.
- **Package contents** — exclude desktop bundles from npm tarballs, omit logs and design drafts from desktop bundles, and expand environment-file and registry-token ignore rules.
