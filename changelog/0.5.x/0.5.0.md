# 0.5.0 — 2026-10-29

## Added

- **`fema-guide` skill** — a published agent skill carrying the gates, identifier sources, and OData filter syntax for the `fema_*` tools (county naming across datasets, dollar totals, NFIP scoping). It ships in the npm package, Docker image, MCPB bundle, and plugin tree, and is served over MCP as `skill://fema-guide/SKILL.md`.

## Changed

- **DataCanvas is on by default.** With `CANVAS_PROVIDER_TYPE` unset, blank, whitespace-only, or an unsubstituted `${…}` placeholder the server uses `duckdb` (0.4.1 needed `duckdb` set); `none` disables it. The Claude Desktop bundle (`manifest.json`) pins `none` because it ships without DuckDB's native bindings, and drops its "Enable DataCanvas deletion" setting.
- **Server `instructions`** state that NFIP claims carry no disaster number and are scoped by state, county FIPS, and loss year, and point at the `DataSets` catalog dataset and the `fema-guide` skill.
- **`fema_query_dataset` `unknown_dataset` recovery** says to list catalog names through `fema_query_dataset` on dataset `DataSets`, replacing a web page link. The `fema_search_nfip` description no longer names `CANVAS_PROVIDER_TYPE`.
- **Tool error text in `content[]`** (message, `Recovery:` hint, reason) gains Markdown backslash escapes; `structuredContent` is unchanged (mcp-ts-core 0.13.16, [cyanheads/mcp-ts-core#760](https://github.com/cyanheads/mcp-ts-core/issues/760)).
- **Enrichment trailer string values** such as the housing tool's `county_filter` and `zip_code_filter` echo render in `content[]` as code spans; `structuredContent` is unchanged (mcp-ts-core 0.13.18, [cyanheads/mcp-ts-core#785](https://github.com/cyanheads/mcp-ts-core/issues/785)).
- **An invalid or out-of-range framework environment variable** fails startup with a banner naming the variable (mcp-ts-core 0.13.16, [cyanheads/mcp-ts-core#746](https://github.com/cyanheads/mcp-ts-core/issues/746), [cyanheads/mcp-ts-core#747](https://github.com/cyanheads/mcp-ts-core/issues/747)).
- **HTTP shutdown** answers `503` with `Retry-After: 1` while draining, and a call cancelled by the client settles as `RequestCancelled` (`-32011`) (mcp-ts-core 0.13.16, [cyanheads/mcp-ts-core#749](https://github.com/cyanheads/mcp-ts-core/issues/749), [cyanheads/mcp-ts-core#753](https://github.com/cyanheads/mcp-ts-core/issues/753)).
- **`fema_dataframe_query` SQL** refuses a bare `current_schema`; the message and recovery hint say to qualify a column of that name with its table (mcp-ts-core 0.13.16 [cyanheads/mcp-ts-core#756](https://github.com/cyanheads/mcp-ts-core/issues/756), 0.13.18 [cyanheads/mcp-ts-core#784](https://github.com/cyanheads/mcp-ts-core/issues/784)).
- **Repo and packaging:** root `plugin.json` and `mcp.json` (Agent Plugins), an expanded `.mcpbignore`, a single Environment table in the issue forms, and a condensed README getting-started section.

## Fixed

- **Re-staging a canvas table is atomic, and an interrupted NFIP spillover closes its source** (mcp-ts-core 0.13.17, [cyanheads/mcp-ts-core#659](https://github.com/cyanheads/mcp-ts-core/issues/659), [cyanheads/mcp-ts-core#661](https://github.com/cyanheads/mcp-ts-core/issues/661)).
