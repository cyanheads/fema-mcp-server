# 0.5.1 — 2026-11-03

## Added

- **Declaration title search** — `fema_search_disasters` accepts an optional case-insensitive `title` substring, combined with existing filters before grouping and paging. Blank input adds no filter; matching a name does not identify a unique storm (#64).
- **Per-area programs** — `fema_get_disaster.designated_areas` exposes and renders each area's `ia_declared`, `pa_declared`, and `hm_declared` flags, including areas with no programs (#60).

## Fixed

- **Legacy IA designations** — search, detail, county rollups, and the disaster resource combine `iaProgramDeclared` with `ihProgramDeclared`, retaining modern IHP-only designations and bounded partial-coverage disclosures. Housing guidance distinguishes IA designation from housing-record availability (#57).
- **County type spellings** — declaration, housing, and PA filters recognize vocabulary-backed terminal County, Parish, Borough, and Census Area names with or without parentheses. Suffixed names retain their type; bare substring matches and unknown-name case fallbacks remain unchanged (#58).
- **Literal result text** — formatters preserve Markdown punctuation, HTML delimiters, and entity-like text as literal values. Controls, line breaks, and edge whitespace select complete fenced JSON rather than lossy table cells; nested values, column names, and enrichment notices remain intact. Raw structured values are unchanged, and row budgets account for escaped or JSON output while preserving whole-row continuation, including oversized NFIP rows (#67).
- **Disaster detail annotation** — `fema_get_disaster` declares `openWorldHint: true`, like the other tools that read OpenFEMA (#60).
