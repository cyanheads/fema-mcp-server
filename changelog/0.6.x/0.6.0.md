# 0.6.0 — 2026-11-21

## Added

- **`fema_get_disaster`** reports disaster-wide funding and FEMA load dates, preserving nulls in reported summaries. Missing or unavailable summaries leave the declaration available with a notice. ([#61](https://github.com/cyanheads/fema-mcp-server/issues/61))
- **`fema_search_nfip`** filters by exact-case `flood_event`, returns the event in inline and staged records, and scopes county coverage checks to the event when supplied. ([#62](https://github.com/cyanheads/fema-mcp-server/issues/62))
- **`fema_get_public_assistance`** adds applicant names matched by disaster and ID, mitigation amounts, padded county FIPS, process steps, and last obligation dates. Failed name lookups leave projects available with a notice. ([#63](https://github.com/cyanheads/fema-mcp-server/issues/63))
- **`fema_get_public_assistance` and `fema_get_housing_assistance`** stage first-page overflow for SQL, with canvas reuse and a 50,000-row cap per table. Operational staging failures preserve inline paging and attempt to roll back new tables. A notice identifies incomplete cleanup on a supplied canvas. ([#66](https://github.com/cyanheads/fema-mcp-server/issues/66))

## Changed

- OpenFEMA HTTP failures omit the captured upstream response from `structuredContent.error.data.body` and `structuredContent.error.data.responseBody`.
- **`fema_dataframe_query`** documents `SHOW <table>` for schema inspection and constant `range()` and `generate_series()` for gap-filling.
- **Bun** now requires 1.4.4 or later.
