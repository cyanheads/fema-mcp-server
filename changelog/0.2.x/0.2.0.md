# 0.2.0 — 2026-09-19

## Changed

- **Canvas tool inputs** — `fema_search_nfip`, `fema_dataframe_describe`, `fema_dataframe_query`, and `fema_dataframe_drop` now require a server-issued `canvas_id` matching `^[A-Za-z0-9_-]{10}$`; invalid IDs are rejected as invalid arguments before canvas lookup.
- **Session mode** — With MCP_SESSION_MODE unset, the server defaults to stateless; an explicit MCP_SESSION_MODE still overrides it.
- **OpenFEMA request budget** — `FEMA_REQUEST_TIMEOUT_MS` now bounds one upstream exchange, including response-body reads, retries, and backoff.
- **Framework behavior** — `@cyanheads/mcp-ts-core` accepts documented camelCase argument aliases, reports invalid arguments before handlers run, and carries declared recovery hints in client error responses.

## Fixed

- **`fema_dataframe_query`** — DataCanvas conversion failures report `sql_execution_error` with TRY_CAST recovery guidance.

## Security

- **OpenFEMA client errors** — error data no longer includes the full request URL, which can contain caller-provided query values.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.12.3 → ^0.13.6
