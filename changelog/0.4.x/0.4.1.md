# 0.4.1 — 2026-10-18

## Changed

- **Empty curated searches** return empty arrays, zero totals, and filter-specific recovery notices instead of `no_results` errors ([#49](https://github.com/cyanheads/fema-mcp-server/issues/49)).
- **`fema_search_nfip` county coverage** discloses state/year claims missing county codes when their count is ready, or reports unchecked coverage, without delaying the primary read or assigning those claims to a county or ZIP ([#53](https://github.com/cyanheads/fema-mcp-server/issues/53)).

## Fixed

- **HTTP 5xx retries** rotate intact encoded query parameters after the first attempt, allowing recovery from URL-specific failures within the existing retry bounds ([#50](https://github.com/cyanheads/fema-mcp-server/issues/50)).
- **PA county matching** includes exact PA spellings such as `LaSalle Parish` and `Chugach REAA`; vocabulary refresh validates both complete exports before atomically replacing the bundled snapshot ([#52](https://github.com/cyanheads/fema-mcp-server/issues/52)).
- **Disaster details and summary resource** disclose capped designated-area reads with `areas_truncated`, `total_designated_area_count`, and guidance to retrieve full rows; program flags describe fetched evidence ([#54](https://github.com/cyanheads/fema-mcp-server/issues/54)).

## Dependencies

- `vitest` ^5.0.4 → ^5.0.5.
